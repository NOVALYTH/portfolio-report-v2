# Design System — Portfolio Report v2

## 📌 **Overview**
Design System moderne pour le **Portfolio Report v2**, optimisé pour :
- **Performance** (100% self-contained, pas de CDN).
- **Maintenabilité** (composants réutilisables, tokens CSS).
- **Accessibilité** (WCAG AAA, contraste > 4.5).
- **Responsive** (mobile-first, breakpoints à 768px/1024px).
